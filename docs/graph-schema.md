# InfraGraph schema

Version 1.0 separates resource identity, resource type, cloud IDs, instance keys and visual groups. Stable node IDs are SHA-256 hashes of canonical addresses; deposed object identity adds a suffix. Resource addresses are preserved in metadata. parseResourceAddress tokenizes module paths outside bracketed quoted keys, including dots and escaped quotes.

Nodes carry provider, resource type/name, mode, module, sanitized attributes, scope, knowledge, evidence and optional change metadata. Replacement actions retain order. Edges carry source/target IDs, relationship type, knowledge and evidence. Known value relations cite state_value or plan_value; configuration relations cite configuration_reference and retain attribute paths. Inference never implies verified packet reachability.

semanticScope expresses known infrastructure associations; layoutParentId is a unique visual choice in ViewModel. Both may remain incomplete. Terraform/OpenTofu cannot reliably be distinguished by the common JSON schema; engine defaults to unknown. Prior-state-only historical rendering is not implemented. `unknownAttributePaths` lists plan values that are unknown until apply. `unresolvedReferencePaths` lists expression paths with a reference that resolved to no resource (var, local, each.value); placement never treats those paths as complete. Collection references whose instance cannot be determined are kept as `references` edges with knowledge `unknown`. Network-view AZ frames are ViewModel-only nodes (`iacviz_availability_zone`) and never enter the InfraGraph. Unknown optional plan fields are ignored safely or summarized as warnings, not exported raw.
