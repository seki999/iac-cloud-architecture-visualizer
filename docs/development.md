# Development

Install Node 22/24 and pnpm 9.15.9. Run pnpm install --frozen-lockfile, pnpm typecheck, pnpm build, pnpm test, pnpm lint. pnpm dev --help starts the source CLI. pnpm examples writes all nine example diagrams. pnpm bench records host-specific cold-process measurements in docs/performance-results.json. pnpm verify:drawio checks generated XML.

Keep schemas/core independent of layout and renderer. Add a regression before repairing a semantic bug. Run focused tests during implementation, then the full checks before delivery. Avoid copying raw JSON objects into exported graph metadata.

Fixture baselines can be intentionally updated with pnpm exec tsx scripts/update-golden.ts. Review the diff: generated snapshots do not provide independent semantic proof. Existing CLI-source provenance is inherited, not independently regenerated by this continuation. Do not execute terraform apply to reproduce fixtures. Dataset 08/09 are synthetic JSON; their main.tf files are provenance notices, not deployable reproductions.
